# Провинция

Экономический симулятор в пиксельной графике: государство выделяет вам деньги на развитие
провинциальной области. Стройте, учитесь, ведите политику, гуляйте по улицам своего города.

Игра — один файл `index.html`, без зависимостей. Откройте его в браузере.

## План работ

1. Исправление ошибок (сделано: «NaN $» в счёте фонда).
2. Режим обучения с наставником.
3. Выбор страны, участка, роли и договор с целями; больше уровней сложности.
4. Новое меню и иконка.
5. Музыка.
6. Графика: выше разрешение, лица, четыре набора текстур.
7. Прогулка с выбором направления.
